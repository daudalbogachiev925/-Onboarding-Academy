# Объекты конфигурации

## Основные объекты

- Справочники — списки однотипных элементов
- Документы — факты хозяйственной деятельности
- Регистры сведений — хранение данных
- Регистры накопления — остатки и обороты
- Отчёты — вывод данных
- Обработки — выполнение действий

## Свойства объектов

- Имя — идентификатор
- Синоним — отображаемое название
- Реквизиты — поля объекта
- Табличные части — таблицы внутри объекта

## Пример

Справочник "Товары":
- Реквизиты: Артикул, Цена, ЕдиницаИзмерения
- Табличная часть: Штрихкоды
